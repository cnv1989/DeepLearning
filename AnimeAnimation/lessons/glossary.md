# Glossary

| Term | Meaning |
|---|---|
| **Ahoge** (アホ毛) | The single antenna-like strand of hair sticking up. Often animated with a spring. |
| **Anticipation** | A small opposite move before the main action (wind-up). |
| **Bank** | Reused stock footage or cycles. |
| **Boil** | Lines redrawn every few frames with small variations so they feel alive. |
| **Cel shading** | Lighting split into flat tones with hard edges. Named after the transparent celluloid sheets once painted by hand. |
| **Chibi** / **SD** | Super-deformed, a 2–3 head-tall cute style. |
| **Douga** (動画) | In-between drawings, and the cleaned final line drawings. |
| **Ekonte** (絵コンテ) | Storyboard. |
| **Exposure sheet** / **X-sheet** / **timesheet** | A frame-by-frame chart of which drawing is shown on each frame, plus dialogue and camera notes. |
| **FK / IK** | Forward kinematics (set the angles, get the positions) and inverse kinematics (set a target position, get the angles). |
| **Follow-through** | Parts that keep moving after the main action stops (hair, cloth). |
| **Genga** (原画) | Key animation: the important poses. |
| **Hold** | Keeping one drawing on screen for several frames. |
| **Impact frame** | 1–3 stylized, often inverted frames at the moment of a hit. |
| **Kuchipaku** (口パク) | Lip flap: simple mouth animation, usually 3 shapes. |
| **On ones / twos / threes** | Each drawing is held for 1, 2 or 3 frames at 24 fps. |
| **Onion skin** | Faded view of the previous and next drawings, used to check spacing. |
| **Sakuga** (作画) | Literally "drawing". Fans use it for standout, high-quality animation sequences. |
| **Satsuei** (撮影) | Compositing / photography: combining layers, camera and effects. |
| **Settei** (設定) | Design sheets: characters, props, color keys. |
| **Shiage** (仕上げ) | Coloring / ink and paint. |
| **Shuuchuusen** (集中線) | Focus lines, radiating toward a subject. |
| **Smear** | A stretched, blurred drawing showing fast motion in a single frame. |
| **Spacing** | How far apart successive drawings are. It sets speed and easing. |
| **Timing** | How many frames an action takes. |
| **Toon shader** | A 3D shader that produces cel-shaded output. |
